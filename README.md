# FruitLens

## Project

FruitLens is a CNN-based fruit image classification project
developed by a team of five students.

## Objective

To develop an application that can identify whether an uploaded
fruit image is an apple or banana and provide information about
the identified fruit.

## Team

FruitLens

## Project Scope

- Apple and banana classification
- Image upload
- CNN-based image classification
- Fruit information
- Testing and evaluation
